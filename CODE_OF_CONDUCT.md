# Code of Conduct

## Our Pledge

We want this project to be welcoming, practical, and respectful. Contributors are expected to be kind, patient, and constructive.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different experience levels.
- Give and receive feedback gracefully.
- Focus criticism on code, documentation, and behavior.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private information without permission.
- Sharing ROMs, BIOS files, or copyrighted artwork through project spaces.
- Repeated disruptive behavior after being asked to stop.

## Enforcement

Project maintainers may remove comments, close issues, or block participants who do not follow this code of conduct.
